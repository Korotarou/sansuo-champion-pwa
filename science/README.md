# 理科ラボ｜SAPIX α1 × 筑駒・開成

Version: v05 (2026-09-10)

小4のSAPIX理科を土台に、α1を目指す日常学習と、筑駒・開成につながる初見考察力を一つにしたPWAです。

## 収録機能

- 今日の15分「α1ルート」：基礎・考察・再テストを自動配分
- SAPIX復習：小4範囲を短時間で確認
- 理科口頭試問：「なぜ？」を自分の言葉で説明
- 知識・原理／実験・観察／表・グラフ／初見考察の分解トレーニング
- 筑駒40分モード：100点想定のオリジナル演習
- 開成40分モード：70点想定のオリジナル演習
- AI禁止テスト：終了までヒント・解説を表示しない
- 誤答原因：知らなかった／原理があいまい／資料・条件の読み違い／知っていたが使えなかった／計算ミス／ケアレスミス
- 復習キュー：誤答・説明不足を翌日以降に再テスト
- α1準備度：正答率だけでなく説明率・上位問題・再確認状況を含むアプリ独自指標
- 生物・地学・物理・化学の単元別習熟度
- 学習記録のJSONバックアップ／復元
- APIキー不要、追加課金なし、オフライン対応

## iPadで使う方法

1. GitHub Pages の公開URLをSafariで開く。
2. Safariの共有ボタン →「ホーム画面に追加」。
3. 以後はホーム画面の「理科ラボ」から起動する。

## 学習設計

- 小4の現在はSAPIX授業理解・基本の取りこぼし防止を最優先にする。
- 正解だけでは理解済みにしない。理由を説明できたかを別に記録する。
- 誤答は翌日以降のAI禁止再テストへ回す。
- 筑駒・開成モードは長期目標。小4の間は日常学習の中心にしない。
- 学校の過去問やSAPIX教材本文は収録せず、問題はオリジナル。

## α1準備度について

SAPIX公式のクラス昇降基準を表すものではありません。校舎・テストごとに基準が変動するため、本アプリでは「基礎正答率」「理由説明」「Lv.3以上の問題」「再確認状況」から学習上の準備度を0〜100で表示します。
