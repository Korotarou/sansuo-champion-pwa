# 算数王438 — 競技算数PWA

最難関中学算数、ジュニア算数オリンピック、算数オリンピックにつながる初見対応力を52週で鍛えるiPad向けPWAです。

公開ソースに利用者の個人名は含めません。プロフィールと学習履歴は端末内に保存します。

本アプリは各学校・算数オリンピック委員会の公式教材ではなく、公式過去問本文は収録していません。

## 保護者ダッシュボード

学習履歴から、今日の再テスト、未定着・△問題、弱点タグ、A〜G誤答原因、今週の実績を一画面で確認できます。SAPIXテスト記録と週の重点も端末内に保存します。

## SAPIXテスト分析エンジン v2.2

SAPIX個人成績票PDFをブラウザ内で読み取り、総合偏差値、算数の分野別得点、設問別の正誤・配点・正答率を解析します。正答率70%以上の取りこぼし、50〜70%の失点、30〜50%で取れた問題、30%未満の難問を分けて表示し、弱点分野をアプリ内の問題推薦へ反映します。

PDF本文、氏名、受験番号は保存しません。PDF解析は端末内で行い、保存するのはテスト名・日付・成績値・設問分析結果・ユーザーが確定したA〜G誤答原因だけです。PDF.jsが読み込めない環境向けにテキスト貼り付け解析も用意しています。

## 継続弱点エンジン v2.3

直近5回のSAPIX解析結果を横断し、単発の失点ではなく再発した弱点を優先します。A〜G誤答原因は手動確定したものだけを集計し、「A〜G入力済み4回中Fが3回」のように表示します。分野は本人得点率と受験者平均の差から再発を検出し、今週直す項目を最大2つに絞ります。

正答率70%以上の取りこぼしが複数テストで続く場合は、新しい難問より優先します。反復した分野は438問エンジンの推薦順位にも反映します。テストごとに難度が異なるため、偏差値推移は参考指標として扱い、それだけで理解度を断定しません。

## 弱点卒業・α1目標 v2.4

SAPIXで正答率50%以上なのに失点した問題を、再テスト対象として追跡します。ヒントなしで正解し、自分の言葉で説明できたことを1回目の合格とし、3日以上空けて同条件で再現できた時点で「卒業」とします。途中で再び失敗した場合は、連続確認をやり直します。

中期目標として「SAPIX α1入室」を常時表示します。α1の基準は校舎・時期・テストで変動するため固定値や推定値は使わず、実際に判明した基準点のみ入力します。最新の4科得点との差と、正答率50%以上で失った回収可能点を比較し、α1へ近づくために何を優先すべきかを表示します。

## α1次回得点設計 v2.5

直近テストで実際に判明したα1基準点を使い、「今回と同じ基準なら何点をどこから回収すれば届いたか」をシミュレーションします。正答率70%以上、50〜70%、30〜50%の順に回収ルートを作り、難問を先に増やさない設計です。

次回のα1基準点は予測しません。登録済みの実基準点の範囲・中央値は参考情報として表示しますが、テスト難度・校舎・時期による変動を前提とします。次回テストでは点数予言ではなく、70%以上の取りこぼし0、再テスト期限の解消、継続弱点の再発防止など、再現可能なプロセス目標を提示します。
