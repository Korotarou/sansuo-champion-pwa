# 算数王438 — 競技算数PWA

最難関中学算数、ジュニア算数オリンピック、算数オリンピックにつながる初見対応力を52週で鍛えるiPad向けPWAです。

公開ソースに利用者の個人名は含めません。プロフィールと学習履歴は端末内に保存します。

本アプリは各学校・算数オリンピック委員会の公式教材ではなく、公式過去問本文は収録していません。

## 保護者ダッシュボード

学習履歴から、今日の再テスト、未定着・△問題、弱点タグ、A〜G誤答原因、今週の実績を一画面で確認できます。SAPIXテスト記録と週の重点も端末内に保存します。

## SAPIXテスト分析エンジン v2.2

SAPIX個人成績票PDFをブラウザ内で読み取り、総合偏差値、算数の分野別得点、設問別の正誤・配点・正答率を解析します。正答率70%以上の取りこぼし、50〜70%の失点、30〜50%で取れた問題、30%未満の難問を分けて表示し、弱点分野をアプリ内の問題推薦へ反映します。

PDF本文、氏名、受験番号は保存しません。PDF解析は端末内で行い、保存するのはテスト名・日付・成績値・設問分析結果・ユーザーが確定したA〜G誤答原因だけです。PDF.jsが読み込めない環境向けにテキスト貼り付け解析も用意しています。
