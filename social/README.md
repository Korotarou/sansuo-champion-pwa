# 社会Lab 418 v02

小学4年生のSAPIX社会を主教材として復習しながら、資料読解・因果説明・記述・再テストを通じて最難関中学につながる初見対応力を育てるiPad向けPWAです。

## v02の収録問題

- 都道府県・県庁所在地・地方区分：94問
- 地理因果：120問
- 歴史：120問（先取り）
- 公民：60問（先取り）
- 初見資料・最難関思考：24問
- 合計：418問

すべて本アプリ用のオリジナル問題です。SAPIX、筑波大学附属駒場中学校、開成中学校の過去問本文は収録していません。

## 小4の既定運用

小4デイリーは地理75%＋初見資料25%です。歴史・公民は通常デイリーに入れず、先取りトラックとして分離しています。設定で少量混ぜることもできます。

52週カリキュラムはアプリ内部の学習設計で、SAPIX公式進度表ではありません。

## 学習設計

- ヒントは一度に1つ
- AI禁止テスト
- A〜G誤答分類は本人・保護者が確定
- ヒント後正解は弱点として再テストへ
- 誤答は翌日を目安に再確認
- 再テストはヒントなし＋説明可能を2回再現して卒業
- 記述はキーワード検出だけで正誤を断定せず、必要要素を表示して自己判定
- LocalStorage保存、JSONバックアップ・復元

## SAPIX α1目標

α1基準点を予測しません。校舎・時期・テストごとに実際に判明した4科基準点のみ入力し、「今回と同じ基準なら何点不足したか」を表示します。

社会では正答率70%以上、50〜70%、30〜50%の取りこぼし点を入力し、回収優先順位を可視化します。

## iPad PWA

HTTPSで公開したURLをSafariで開き、共有 → ホーム画面に追加、で利用できます。初回読み込み後は主要ファイルをService Workerへキャッシュします。

## データとプライバシー

答案・学習履歴・テスト入力値は端末のブラウザ内に保存し、この版は外部APIへ送信しません。公開ソースに利用者の氏名・学校・成績は含めません。
